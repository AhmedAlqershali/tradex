Tradex Backend Code Organization & Developer Documentation Phase

Goal:
Organize and document the Laravel backend so a human developer can understand, maintain, and modify the project easily without AI assistance.

Important:
Do not change business logic.
Do not change API behavior.
Do not remove working features.
Only improve structure, readability, and documentation.

Tasks:

1. Backend Structure Audit

Review the complete Laravel project and organize:

- Controllers
- Services
- Repositories
- Models
- Requests
- Resources
- Policies
- Middleware
- Jobs
- Events
- Notifications
- AI services
- Configuration files

Ensure every file has a clear responsibility.

If any file contains too much logic:
- Refactor carefully.
- Keep the same functionality.
- Preserve all tests.
